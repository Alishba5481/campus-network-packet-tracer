# Campus-network-packet-tracer

A campus network simulated in Cisco Packet Tracer, connecting 7 departments through a chain of routers.

## Features
- RIP routing across 8 routers
- VLAN 10 (SE) and VLAN 20 (CS) with inter-VLAN routing
- DHCP and DNS servers
- SSH (admin) and Telnet (library) remote access
- GRE tunnel between the lab and physics routers
